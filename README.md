# SecRep для ученика

Откройте site/index.html в браузере для предпросмотра. Страница работает без сборки.

## Публикация

Содержимое этой папки, включая .github, должно лежать в корне отдельного репозитория с основной веткой main. В Settings → Pages → Build and deployment выберите GitHub Actions. Запустите «Публикация гайда» в Actions или отправьте изменение site/ в main. Адрес сайта появится в окружении github-pages.

Перед рассылкой пройдите инструкции под тестовым учеником. Проверьте получение уведомлений на iPhone и Android и сообщения от обоих ботов. Снимки SecRep сделаны из компонентов интерфейса с учебными данными. Снимки Safari взяты из инструкции по установке SecRep.
